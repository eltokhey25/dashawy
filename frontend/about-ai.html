عن مشروع دشاوي

خدمة متخصصة في تركيب وصيانة أطباق الدش والرسيفرات في الإسكندرية، مصر.
Satellite dish installation, maintenance, signal tuning and receiver service in Alexandria, Egypt.

ما الذي يفعله دشاوي؟

دشاوي منصة تربط العملاء بفنيي تركيب وصيانة أطباق الدش المتخصصين والمُوثَّقين في محافظة الإسكندرية. العميل يطلب خدمة، والنظام يوصلها لأقرب فني متاح — بدون مكالمات ولا مفاوضات ولا انتظار بلا نهاية.

عند إنشاء الطلب، يُبَثّ الطلب إلى كل الفنيين المتاحين والمؤهلين في نطاق سكن العميل دفعةً واحدة، وأول فني يقبل هو صاحب الطلب. ولو مفيش فني متاح في تلك اللحظة، الطلب ما بيترفضش: يفضل بحالة «قيد البحث عن فني متاح»، ويتعرض تلقائياً على أول فني يبقى متاح — سواء فوراً عند انتهاء الفني من شغله، أو من مسح دوري كل دقيقتين.

A customer requests one of four services — dish installation, dish repair, signal tuning, receiver service. The request is broadcast to every eligible technician within range, and the first to accept wins it. If nobody is available the request is never rejected: it stays pending and is offered to the first technician who frees up, either immediately or on a two-minute background sweep.

الخصائص الأساسية

الفرد والعميل

  • تسجيل ذاتي للفنيين مع رفع بطاقة الرقم القومي وصحيفة الحالة الجنائية، واعتماد من الأدمن قبل الظهور في نظام البث.
  • توزيع تلقائي حسب المنطقة الجغرافية والتوافر، مع مراعاة حد المسافة وسقف المديونية. كل الفنيين يغطون كل خدمات الدش.
  • 42 منطقة في الإسكندرية مغطاة، مع اقتراح تلقائي للموقع.
  • الطلب المعلق ما يضيعش: يُعاد عرضه باستمرار، ويُلغى بعد 24 ساعة مع سبب واضح.
  • نظام Start PIN: كود من 4 أرقام يقرؤه العميل عند الباب، فلا يستطيع أحد غير الفني بدء شغلته.
  • تأكيد المبلغ من الطرفين: الفني يبلّغ بما استلمه والعميل يؤكد نفس الرقم، وأي اختلاف يوقف الطلب للمراجعة.
  • تقييم إلزامي بعد كل مهمة، ومحادثة داخل كل طلب، وإشعارات Web Push.

الإدارة والمال

  • لوحة تحكم كاملة: الطلبات، الفنيين، العملاء، المراجعات، المحفظة والمالية، التخصصات والأسعار، المديرون، وطلبات حذف البيانات.
  • محفظة لكل فني: عمولة محسوبة، حد مديونية، وسحوبات بمراجعة إدارية.
  • تطبيق ويب تقدمي (PWA) يعمل بدون إنترنت ويصلح تثبيته على الشاشة الرئيسية.
Technician self-registration with ID and criminal-record upload, admin approval, automatic distribution by area and availability, 42 Alexandria neighbourhoods, pending requests that are re-offered rather than dropped, a doorstep Start PIN, two-sided cash confirmation, mandatory reviews, per-request chat, Web Push, a full admin dashboard, and a per-technician wallet.

التقنيات المستخدمة

الواجهة الخلفية — Node.js + Express
JavaScript بـ CommonJS، Express مع مصادقة JWT ومحدّد معدل الطلبات ورؤوس أمان.
قاعدة البيانات — SQLite
عبر better-sqlite3: ملف واحد بوضع WAL، بلا خادم قاعدة بيانات ولا عمليات تشغيل.
الواجهة الأمامية — HTML/CSS/JavaScript خام
بدون إطار عمل، بدون حزم بناء، وبدون خطوة compile. الصفحات تُخدَم من نفس عملية Express التي تخدم الـ API.
المصادقة — JWT (HS256) + bcrypt
أدوار: عميل / فني / أدمن، وصلاحيات دقيقة، ورمز دخول Start PIN لكل مهمة.
الإشعارات — Web Push (VAPID)
إشعار فوري للفني عند وصول طلب جديد يطابق نطاقه.
الاستضافة — Railway
النشر من مستودع GitHub مع متغيرات بيئة مُدارة.
Backend: Node.js + Express. Database: SQLite via better-sqlite3 (single file, WAL, no server). Frontend: vanilla HTML/CSS/JS with no framework and no build step. Auth: JWT (HS256) + bcrypt. Notifications: Web Push. Hosting: Railway.
